# 一元积分学

## 一、原函数与不定积分

### 1.1 原函数

设 $F(x)$ 与 $f(x)$ 在某区间 $I$ 上有定义,若在 $I$ 上 $F'(x) = f(x)$,则称 $F(x)$ 是 $f(x)$ 的一个**原函数**。

若 $F(x)$ 是 $f(x)$ 的一个原函数,则 $F(x) + C$ 也是 $f(x)$ 的原函数(其中 $C$ 为任意常数)。即一个函数的原函数若有,则有无穷多个。

### 1.2 不定积分

$f(x)$ 的全体原函数称为 $f(x)$ 的**不定积分**,记作:
$$\int f(x) dx = F(x) + C$$

其中 $\int$ 称为积分号,$f(x)$ 称为被积函数,$f(x)dx$ 称为被积表达式,$x$ 称为积分变量,$C$ 称为积分常数。

## 二、基本积分公式

- $\int 0 \, dx = C$
- $\int x^a \, dx = \frac{x^{a+1}}{a+1} + C$ $(a \neq -1)$
- $\int \frac{1}{x} dx = \ln |x| + C$
- $\int e^x dx = e^x + C$
- $\int \sin x \, dx = -\cos x + C$
- $\int \cos x \, dx = \sin x + C$
- $\int \sec^2 x \, dx = \tan x + C$

## 三、积分方法

### 3.1 换元积分法

设 $F(u)$ 是 $f(u)$ 的原函数,$u = \varphi(x)$ 可导,则:
$$\int f(\varphi(x)) \varphi'(x) dx = F(\varphi(x)) + C$$

### 3.2 分部积分法

设 $u = u(x), v = v(x)$ 连续可导,则:
$$\int u dv = uv - \int v du$$

适用于乘积形式的积分,特别是 $\int x^n e^x dx$、$\int x \sin x \, dx$ 等。

## 四、定积分

### 4.1 定义

设 $f(x)$ 在 $[a,b]$ 上有界,将 $[a,b]$ 任意分成 $n$ 个小区间,在每个小区间上任取一点 $\xi_i$,令 $\lambda = \max\{\Delta x_i\}$。若极限
$$\lim_{\lambda \to 0} \sum_{i=1}^{n} f(\xi_i) \Delta x_i$$
存在,则称 $f(x)$ 在 $[a,b]$ 上**可积**,并称此极限为 $f(x)$ 在 $[a,b]$ 上的**定积分**,记作:
$$\int_a^b f(x) dx$$

### 4.2 几何意义

$\int_a^b f(x) dx$ 表示由曲线 $y = f(x)$、直线 $x = a$、$x = b$ 与 $x$ 轴所围成的**有向面积**($x$ 轴上方为正,下方为负)。

### 4.3 牛顿-莱布尼茨公式

若 $F(x)$ 是 $f(x)$ 在 $[a,b]$ 上的一个原函数,则:
$$\int_a^b f(x) dx = F(b) - F(a)$$

这是联系定积分与不定积分的桥梁。

## 五、定积分的应用

### 5.1 几何应用

- **平面图形面积**:$S = \int_a^b |f(x) - g(x)| dx$
- **旋转体体积**:$V = \pi \int_a^b [f(x)]^2 dx$

### 5.2 物理应用

- **变力做功**:$W = \int_a^b F(x) dx$
- **液压力**:$F = \int_a^b \rho g h(x) L(x) dx$

## 六、反常积分

### 6.1 无穷限的反常积分

设 $F(x)$ 是 $f(x)$ 的原函数,若极限 $\lim_{b \to +\infty} F(b)$ 存在,则定义:
$$\int_a^{+\infty} f(x) dx = \lim_{b \to +\infty} [F(b) - F(a)]$$

### 6.2 无界函数的反常积分

若 $f(x)$ 在 $x = b$ 附近无界,定义:
$$\int_a^b f(x) dx = \lim_{\varepsilon \to 0^+} \int_a^{b-\varepsilon} f(x) dx$$

## 七、典型例题

**例 1**:求 $\int x e^x dx$。

解:用分部积分法,令 $u = x$,$dv = e^x dx$,则 $du = dx$,$v = e^x$。
$$\int x e^x dx = x e^x - \int e^x dx = x e^x - e^x + C = (x-1)e^x + C$$

**例 2**:求 $\int_0^1 (3x^2 + 2x) dx$。

解:由牛顿-莱布尼茨公式:
$$\int_0^1 (3x^2 + 2x) dx = [x^3 + x^2]_0^1 = 1 + 1 - 0 = 2$$

**例 3**:求 $\int_0^{+\infty} e^{-x} dx$。

解:$\int_0^{+\infty} e^{-x} dx = \lim_{b \to +\infty} [-e^{-x}]_0^b = \lim_{b \to +\infty} (1 - e^{-b}) = 1$。
