## 一、分治法

### 1.1 思想

将原问题分解为若干个与原问题结构相同但规模更小的子问题,递归地解决子问题,然后将子问题的解合并得到原问题的解。

**适用条件**:
1. 问题可分解为若干规模较小的相同问题。
2. 子问题可独立求解。
3. 子问题的解可合并为原问题的解。
4. 子问题分解到足够小时可直接求解。

### 1.2 经典例子:归并排序

**思路**:将数组从中间分成两半,分别排序,然后合并两个有序数组。

**复杂度**:$T(n) = 2T(n/2) + O(n) = O(n \log n)$。

### 1.3 经典例子:快速排序

**思路**:选一个基准元素,将数组分为"小于基准"和"大于基准"两部分,递归排序两个子数组。

**复杂度**:平均 $O(n \log n)$,最坏 $O(n^2)$(选到极端基准)。

## 二、动态规划

### 2.1 思想

将问题分解为相互重叠的子问题,自底向上地解决子问题,并将每个子问题的解保存下来,避免重复计算。

**适用条件**:
1. **最优子结构**:问题的最优解包含子问题的最优解。
2. **子问题重叠**:不同子问题有公共的子子问题。
3. **无后效性**:某阶段状态确定后,后续过程不受之前决策的影响。

### 2.2 经典例子:0-1 背包

**问题**:$n$ 个物品,重量 $w_i$,价值 $v_i$,背包容量 $W$。求最大价值。

**状态**:`dp[i][j]` = 前 $i$ 个物品在容量 $j$ 下的最大价值。

**转移方程**:
$$dp[i][j] = \begin{cases} dp[i-1][j] & \text{不选物品 } i \\ dp[i-1][j-w_i] + v_i & \text{选物品 } i \end{cases}$$

取两者最大值。

**复杂度**:$O(nW)$。

### 2.3 经典例子:最长公共子序列(LCS)

**问题**:求两个序列的最长公共子序列长度。

**状态**:`dp[i][j]` = $A[1..i]$ 与 $B[1..j]$ 的 LCS 长度。

**转移方程**:
$$dp[i][j] = \begin{cases} 0 & i=0 \text{ or } j=0 \\ dp[i-1][j-1] + 1 & A[i] = B[j] \\ \max(dp[i-1][j], dp[i][j-1]) & A[i] \neq B[j] \end{cases}$$

**复杂度**:$O(mn)$。

## 三、贪心算法

### 3.1 思想

在每一步选择中,都采取当前状态下"看起来最优"的选择(局部最优),希望得到全局最优解。

**适用条件**:
1. **贪心选择性质**:局部最优能导致全局最优。
2. **最优子结构**:问题的最优解包含子问题的最优解。

### 3.2 经典例子:活动选择

**问题**:在不相交的时间区间内选最多活动。

**策略**:按结束时间从小到大排序,每次选最早结束且与已选不冲突的活动。

### 3.3 经典例子:霍夫曼编码

**问题**:给字符集构造二进制前缀码,使编码后总长度最小。

**策略**:每次合并频率最小的两个节点,生成新节点作为它们的父节点。

## 四、回溯法

### 4.1 思想

深度优先搜索解空间树,遇到不满足约束的分支就**剪枝**回溯,寻找所有解(或最优解)。

**适用问题**:
- 找出所有解:N 皇后、子集和、全排列
- 找出最优解:旅行商问题

### 4.2 经典例子:N 皇后

**问题**:在 $N \times N$ 棋盘上放 $N$ 个皇后,使其互不攻击。

**思路**:逐行放置,每行选一列,检查是否与已放置的皇后冲突(同列、同对角线),若冲突则跳过。

**复杂度**:指数级,但剪枝后大幅降低。

### 4.3 经典例子:子集和

**问题**:从集合中选若干元素,使其和等于目标值 $S$。

**思路**:对每个元素选/不选两种决策,递归搜索。

## 五、分支限界法

### 5.1 思想

类似回溯,但用**广度优先**或**最小耗费优先**策略搜索解空间,配合剪枝函数,通常用于求最优解。

**特点**:
- **优先队列**:每次从活节点表选最优节点扩展
- **上界/下界函数**:剪去不可能产生最优解的分支

### 5.2 应用

旅行商问题(TSP)、0-1 背包(求最优解)、任务分配。

## 六、字符串匹配算法

### 6.1 KMP 算法

**问题**:在主串 $T$ 中找模式串 $P$ 的所有出现位置。

**思想**:利用已匹配信息,避免主串指针回溯。通过 `next` 数组记录模式串的最长公共前后缀。

**复杂度**:$O(n + m)$。

### 6.2 Rabin-Karp 算法

**思想**:用哈希函数计算模式串与各文本子串的哈希值,匹配哈希值相等的子串。

**复杂度**:平均 $O(n + m)$,最坏 $O(nm)$。

## 七、NP 完全问题

### 7.1 P 与 NP

- **P 类**:存在多项式时间算法的问题
- **NP 类**:能在多项式时间内**验证解的正确性**的问题
- 显然 $P \subseteq NP$

### 7.2 NP 完全问题

满足两个条件:
1. 是 NP 类问题
2. 所有 NP 问题都能多项式时间归约到它

**经典 NP 完全问题**:SAT、旅行商(TSP)、0-1 背包(决策版)、图着色、团、哈密顿回路、子集和等。

### 7.3 处理策略

- **精确算法**:指数级(只适合小规模)
- **近似算法**:多项式级,保证近似比
- **启发式算法**:如贪心、局部搜索、模拟退火、遗传算法

## 八、典型例题

**例 1**:用分治法求最大子数组和(LeetCode 53)。

**解法**:分治将数组从中点分为左右两部分,最大子数组要么全在左、全在右,或跨越中点。
```python
def max_subarray(nums):
    def helper(left, right):
        if left == right: return nums[left]
        mid = (left + right) // 2
        left_max = helper(left, mid)
        right_max = helper(mid + 1, right)
        # 跨越中点
        left_sum = right_sum = 0
        l_max = r_max = float('-inf')
        for i in range(mid, left - 1, -1):
            left_sum += nums[i]
            l_max = max(l_max, left_sum)
        for i in range(mid + 1, right + 1):
            right_sum += nums[i]
            r_max = max(r_max, right_sum)
        return max(left_max, right_max, l_max + r_max)
    return helper(0, len(nums) - 1)
```

**复杂度**:$O(n \log n)$。

**例 2**:用动态规划爬楼梯问题(每次爬 1 或 2 阶,求爬 $n$ 阶的方法数)。

**解法**:
- 状态:`dp[i]` = 爬 $i$ 阶的方法数
- 转移:`dp[i] = dp[i-1] + dp[i-2]`
- 初始:`dp[1] = 1, dp[2] = 2`
- 答案:`dp[n]`

**例 3**:用贪心算法找零钱(硬币面额 1, 5, 10, 25,求找零 $n$ 元的最少硬币数)。

**解法**:每步选面额最大的硬币(不超过剩余金额),直到找零完成。
- 找零 41:25+10+5+1 = 4 枚
- 找零 30:25+5 = 2 枚

贪心在常见面额下是最优的,但对特殊面额(如 1, 3, 4)贪心不最优(找零 6:贪心 4+1+1=3 枚,实际 3+3=2 枚)。
