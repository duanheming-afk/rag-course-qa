# 多维随机变量与联合分布

> 合成讲义 · 仅供 RAG 系统测试使用 · 学科:概率论与数理统计

## 一、二维随机变量

### 1.1 定义

设 $X = X(\omega)$,$Y = Y(\omega)$ 是定义在同一样本空间 $\Omega$ 上的两个随机变量,则称 $(X, Y)$ 为**二维随机变量**(或**随机向量**)。

### 1.2 联合分布函数

$$F(x, y) = P(X \leq x, Y \leq y)$$
称为 $(X, Y)$ 的**联合分布函数**。

**性质**:
- 关于每个变量单调非减、右连续。
- $F(-\infty, y) = F(x, -\infty) = 0$,$F(+\infty, +\infty) = 1$。

## 二、二维离散型随机变量

### 2.1 联合分布律

设 $(X, Y)$ 取值为 $(x_i, y_j)$ 的概率为 $p_{ij}$,则
$$P(X = x_i, Y = y_j) = p_{ij}, \quad i, j = 1, 2, \ldots$$
为**联合分布律**。满足 $p_{ij} \geq 0$,$\sum_{i,j} p_{ij} = 1$。

### 2.2 边缘分布

由联合分布律可求边缘分布:
$$P(X = x_i) = \sum_{j} p_{ij} = p_{i \cdot}$$
$$P(Y = y_j) = \sum_{i} p_{ij} = p_{\cdot j}$$

## 三、二维连续型随机变量

### 3.1 联合密度函数

若存在非负函数 $f(x, y)$ 使得
$$F(x, y) = \int_{-\infty}^{x} \int_{-\infty}^{y} f(u, v) dv du$$
则称 $(X, Y)$ 为**二维连续型随机变量**,$f(x, y)$ 为**联合密度函数**。

**性质**:
- $f(x, y) \geq 0$
- $\int_{-\infty}^{+\infty} \int_{-\infty}^{+\infty} f(x, y) dx dy = 1$

### 3.2 边缘密度

$$f_X(x) = \int_{-\infty}^{+\infty} f(x, y) dy$$
$$f_Y(y) = \int_{-\infty}^{+\infty} f(x, y) dx$$

## 四、条件分布

### 4.1 离散型条件分布律

对 $P(Y = y_j) > 0$:
$$P(X = x_i | Y = y_j) = \frac{P(X = x_i, Y = y_j)}{P(Y = y_j)} = \frac{p_{ij}}{p_{\cdot j}}$$

### 4.2 连续型条件密度

对 $f_Y(y) > 0$:
$$f_{X|Y}(x | y) = \frac{f(x, y)}{f_Y(y)}$$

## 五、随机变量的独立性

### 5.1 定义

若对任意实数 $x, y$:
$$F(x, y) = F_X(x) F_Y(y)$$
则称 $X$ 与 $Y$ **相互独立**。

**等价表述**:
- 离散:$p_{ij} = p_{i \cdot} p_{\cdot j}$
- 连续:$f(x, y) = f_X(x) f_Y(y)$

### 5.2 性质

若 $X$ 与 $Y$ 独立,则:
- $E[g(X) h(Y)] = E[g(X)] E[h(Y)]$
- $X + Y$ 的方差:$D(X + Y) = D(X) + D(Y)$
- $g(X)$ 与 $h(Y)$ 独立(对任意函数 $g, h$)

## 六、二维正态分布

### 6.1 定义

设 $(X, Y)$ 服从二维正态分布 $N(\mu_1, \mu_2, \sigma_1^2, \sigma_2^2, \rho)$,其联合密度为:
$$f(x, y) = \frac{1}{2\pi \sigma_1 \sigma_2 \sqrt{1 - \rho^2}} \exp\left\{ -\frac{1}{2(1-\rho^2)} \left[ \frac{(x-\mu_1)^2}{\sigma_1^2} - \frac{2\rho(x-\mu_1)(y-\mu_2)}{\sigma_1 \sigma_2} + \frac{(y-\mu_2)^2}{\sigma_2^2} \right] \right\}$$

其中 $\rho$ 是 $X$ 与 $Y$ 的**相关系数**。

### 6.2 重要性质

- $X \sim N(\mu_1, \sigma_1^2)$,$Y \sim N(\mu_2, \sigma_2^2)$ (边缘分布仍为正态)。
- $X$ 与 $Y$ 独立的充要条件是 $\rho = 0$。
- $(X, Y)$ 的任意线性组合 $aX + bY$ 仍服从正态分布。

## 七、典型例题

**例 1**:设 $(X, Y)$ 的联合分布律为:

| $X \backslash Y$ | 0 | 1 |
|---|---|---|
| 0 | 0.1 | 0.2 |
| 1 | 0.3 | 0.4 |

求:(1) 边缘分布;(2) $P(X = 0 | Y = 1)$。

解:
(1) $P(X = 0) = 0.1 + 0.2 = 0.3$,$P(X = 1) = 0.3 + 0.4 = 0.7$。
$P(Y = 0) = 0.1 + 0.3 = 0.4$,$P(Y = 1) = 0.2 + 0.4 = 0.6$。

(2) $P(X = 0 | Y = 1) = P(X = 0, Y = 1) / P(Y = 1) = 0.2 / 0.6 = 1/3$。

**例 2**:设二维随机变量 $(X, Y)$ 的联合密度函数为
$$f(x, y) = \begin{cases} e^{-(x+y)}, & x > 0, y > 0 \\ 0, & \text{其他} \end{cases}$$
问 $X$ 与 $Y$ 是否独立?

解:由对称性,先求边缘密度:
$$f_X(x) = \int_0^{+\infty} e^{-(x+y)} dy = e^{-x}, \quad x > 0$$
$$f_Y(y) = \int_0^{+\infty} e^{-(x+y)} dx = e^{-y}, \quad y > 0$$

由于 $f(x, y) = e^{-(x+y)} = e^{-x} \cdot e^{-y} = f_X(x) f_Y(y)$ 对所有 $x > 0, y > 0$ 成立,故 $X$ 与 $Y$ 独立。

**例 3**:设 $X \sim U(0, 1)$,$Y \sim U(0, 1)$ 且独立,求 $Z = X + Y$ 的密度函数。

解:由卷积公式:
$$f_Z(z) = \int_{-\infty}^{+\infty} f_X(x) f_Y(z - x) dx$$

由于 $f_X, f_Y$ 都在 $(0, 1)$ 上为 1,其他为 0,需要 $0 < x < 1$ 且 $0 < z - x < 1$,即 $\max(0, z-1) < x < \min(1, z)$。

- 当 $z \leq 0$ 或 $z \geq 2$:$f_Z(z) = 0$
- 当 $0 < z \leq 1$:$f_Z(z) = \int_0^z 1 dx = z$
- 当 $1 < z < 2$:$f_Z(z) = \int_{z-1}^{1} 1 dx = 2 - z$

$$f_Z(z) = \begin{cases} z, & 0 < z \leq 1 \\ 2 - z, & 1 < z < 2 \\ 0, & \text{其他} \end{cases}$$

这是著名的**三角分布**。
