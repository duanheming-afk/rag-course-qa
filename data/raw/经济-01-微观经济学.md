## 一、供求理论

### 1.1 需求

**需求**:消费者在一定时期内,在各种可能的价格下,愿意且能够购买的商品数量。

**需求函数**:$Q_d = f(P)$,一般价格越高,需求越少(需求规律)。

**需求曲线**:横轴为需求量 $Q$,纵轴为价格 $P$,向右下方倾斜。

**影响需求的因素**:
- 商品自身价格
- 消费者收入
- 相关商品价格(替代品、互补品)
- 消费者偏好
- 预期

### 1.2 供给

**供给**:生产者在一定时期内,在各种可能的价格下,愿意且能够提供的商品数量。

**供给函数**:$Q_s = g(P)$,一般价格越高,供给越多(供给规律)。

**供给曲线**:向右上方倾斜。

**影响供给的因素**:
- 商品自身价格
- 生产成本(要素价格、技术)
- 相关商品价格
- 生产者预期
- 政府政策(税收、补贴)

### 1.3 均衡

**市场均衡**:供给等于需求时的状态。
- 均衡价格 $P^*$:供需相等的价格
- 均衡数量 $Q^*$:均衡价格下的交易量

**均衡变动**:
- 需求增加 → 均衡价格上升、数量增加
- 需求减少 → 均衡价格下降、数量减少
- 供给增加 → 均衡价格下降、数量增加
- 供给减少 → 均衡价格上升、数量减少

### 1.4 弹性

**需求价格弹性**:
$$E_d = -\frac{\Delta Q / Q}{\Delta P / P} = -\frac{dQ}{dP} \cdot \frac{P}{Q}$$

- $|E_d| > 1$:富有弹性(奢侈品)
- $|E_d| < 1$:缺乏弹性(必需品)
- $|E_d| = 1$:单位弹性

**需求收入弹性**:
$$E_m = \frac{\Delta Q / Q}{\Delta M / M}$$
$E_m > 0$:正常品;$E_m > 1$:奢侈品;$0 < E_m < 1$:必需品;$E_m < 0$:低档品。

**需求交叉价格弹性**:
$$E_{xy} = \frac{\Delta Q_x / Q_x}{\Delta P_y / P_y}$$
$E_{xy} > 0$:替代品;$E_{xy} < 0$:互补品。

## 二、消费者行为理论

### 2.1 效用

**效用**:消费者从消费商品中获得的满足程度。

**基数效用论**:效用可量化(加总、比较大小)。
**序数效用论**:效用不可量化,只可排序(偏好序)。

### 2.2 边际效用递减规律

在一定时间内,其他商品消费量不变时,消费者从连续增加的某商品消费中得到的边际效用(MU)递减。
$$MU = \frac{\Delta TU}{\Delta Q}$$

### 2.3 消费者均衡

在预算约束下,实现效用最大化的条件:
$$\frac{MU_x}{P_x} = \frac{MU_y}{P_y} = \lambda$$

即每元钱花在两种商品上的边际效用相等。

### 2.4 无差异曲线

**无差异曲线**:给消费者带来相同效用水平的两种商品组合的轨迹。

**特征**:
- 向右下方倾斜(替代关系)
- 互不相交
- 凸向原点(边际替代率递减)

**边际替代率(MRS)**:$MRS_{xy} = -\frac{dy}{dx} = \frac{MU_x}{MU_y}$,无差异曲线斜率的绝对值。

### 2.5 预算线

$$P_x x + P_y y = M$$
斜率为 $-P_x/P_y$。

### 2.6 消费者最优选择

无差异曲线与预算线的**切点**。该点满足:
$$MRS_{xy} = \frac{P_x}{P_y}$$

## 三、生产理论

### 3.1 生产函数

描述投入与产出之间技术关系的函数。短期:至少一种要素固定;长期:所有要素可变。

**短期生产函数**:$Q = f(L, \bar{K})$
**长期生产函数**:$Q = f(L, K)$

### 3.2 短期生产

**总产量** $TP$、**平均产量** $AP = TP/L$、**边际产量** $MP = \Delta TP / \Delta L$。

**边际报酬递减规律**:在其他要素不变时,连续增加某要素,其边际产量最终会递减。

**生产的三阶段**:
- 阶段 I:$MP$ 上升,$AP$ 也上升
- 阶段 II:$MP$ 下降但 $MP > 0$,$AP$ 最高后下降(理性选择)
- 阶段 III:$MP < 0$,$TP$ 下降

生产者会在**阶段 II**中某点生产。

### 3.3 长期生产:规模报酬

- **规模报酬递增**:所有要素同比例增加,产出增加更多
- **规模报酬不变**:产出同比例增加
- **规模报酬递减**:产出增加更少

## 四、成本理论

### 4.1 短期成本

- **总固定成本 TFC**:不随产量变化的成本(如厂房租金)
- **总可变成本 TVC**:随产量变化的成本(如原材料)
- **总成本 TC = TFC + TVC**
- **平均固定成本 AFC = TFC/Q**
- **平均可变成本 AVC = TVC/Q**
- **平均成本 AC = TC/Q**
- **边际成本 MC = ΔTC/ΔQ**

短期成本曲线关系:
- MC 曲线先降后升(U 形)
- AC 曲线 U 形,最低点在 MC = AC 处
- AVC 曲线 U 形,最低点在 MC = AVC 处

### 4.2 长期成本

- **长期总成本 LTC**:长期中可调整所有要素
- **长期平均成本 LAC**:LTC/Q,通常 U 形,反映规模经济与不经济
- **长期边际成本 LMC**:LTC 的导数

## 五、市场结构

### 5.1 完全竞争

**特征**:大量买卖者、产品同质、信息完全、自由进出。

**短期均衡**:$P = MC$(利润最大化条件)。
- $P > AC$:有经济利润
- $P = AC$:正常利润
- $P < AC$:亏损,可能停产

**长期均衡**:经济利润为零(自由进出调整),$P = MC = AC_{min}$。

### 5.2 完全垄断

**特征**:唯一卖者、产品无替代、进入壁垒高。

**定价**:边际收益 $MR = MC$ 决定产量,价格由需求曲线决定。
- 垄断者可以实行**价格歧视**(对不同消费者定不同价格)
- 长期仍有经济利润(进入壁垒保护)

### 5.3 垄断竞争

**特征**:许多卖者、产品有差异、进出容易。

**长期均衡**:经济利润为零,但生产能力有闲置($P > AC_{min}$)。
- 主要竞争手段:产品差异、广告

### 5.4 寡头垄断

**特征**:少数卖者、相互依存、进出困难。

**典型模型**:
- **古诺模型**:假设对手产量不变,同时决定各自产量
- **伯特兰模型**:假设对手价格不变,价格竞争
- **斯威齐模型**:价格刚性(降价不跟进,涨价跟着涨)

## 六、市场失灵与政府干预

### 6.1 市场失灵

- **外部性**:生产或消费对第三方有未补偿的影响(正/负)
- **公共物品**:非排他性、非竞争性,市场供给不足
- **信息不对称**:一方信息多于另一方(逆向选择、道德风险)
- **垄断**:竞争不足导致效率损失
- **收入分配不公**

### 6.2 政府对市场的干预

- **税收**:增加财政收入、纠正负外部性
- **补贴**:鼓励正外部性商品
- **价格管制**:最高限价(防止过高)、最低限价(保护生产者)
- **反垄断法**:限制垄断行为
- **公共物品提供**:政府直接生产或采购

## 七、典型例题

**例 1**:某商品需求函数 $Q_d = 100 - 2P$,供给函数 $Q_s = 10 + P$。求均衡价格与数量。

解:均衡条件 $Q_d = Q_s$:
$100 - 2P = 10 + P$
$3P = 90$
$P^* = 30$
$Q^* = 10 + 30 = 40$

**例 2**:某商品价格从 10 元上升到 12 元,需求量从 100 件降到 80 件。求需求价格弹性。

解:$\Delta P / P = 2/10 = 0.2$,$\Delta Q / Q = -20/100 = -0.2$。
$E_d = -(-0.2) / 0.2 = 1$(单位弹性)。

**例 3**:完全竞争厂商 $P = 10$,$AC = 8$,$MC = 10$。问是否应继续生产?

解:虽然 $P > AC$ 有利润(每单位利润 2 元),但应进一步判断是否增产。
由 $P = MC$(10 = 10),已达到利润最大化点,**不应再增产**。
现有产量水平上,每单位利润 2 元,应维持。
