## 一、基本概念

### 1.1 数据结构的研究对象

数据结构研究的是**数据的逻辑结构、存储结构及其操作**。它要解决的核心问题是:**如何高效地组织、存储和操作数据**。

### 1.2 数据的逻辑结构

数据元素之间的逻辑关系:
- **集合结构**:元素除了"同属一个集合"外无其他关系。
- **线性结构**:元素之间是一对一的关系(如数组、链表)。
- **树形结构**:元素之间是一对多的关系(如文件系统)。
- **图状结构**:元素之间是多对多的关系(如社交网络)。

### 1.3 数据的存储结构

数据在计算机中的物理表示:
- **顺序存储**:在连续的内存空间中存储(如数组)。
- **链式存储**:在任意的内存单元中,通过指针串联(如链表)。
- **索引存储**:建立索引表加速查找。
- **散列存储**:通过哈希函数直接计算存储位置。

## 二、算法分析

### 2.1 算法的特性

一个算法应具备以下五个特性:
- **有穷性**:必须在有限步内结束。
- **确定性**:每一步都有确切含义,无歧义。
- **可行性**:每一步都能通过基本操作实现。
- **输入**:有零个或多个输入。
- **输出**:有一个或多个输出。

### 2.2 时间复杂度

算法执行时间随问题规模 $n$ 增长的趋势,用大 O 记号表示:

| 复杂度 | 名称 | 示例 |
|--------|------|------|
| $O(1)$ | 常数 | 数组按下标访问 |
| $O(\log n)$ | 对数 | 二分查找 |
| $O(n)$ | 线性 | 数组遍历 |
| $O(n \log n)$ | 线性对数 | 快速排序(平均) |
| $O(n^2)$ | 平方 | 冒泡排序 |
| $O(2^n)$ | 指数 | 暴力枚举子集 |
| $O(n!)$ | 阶乘 | 暴力枚举排列 |

### 2.3 空间复杂度

算法执行过程中所需额外存储空间随 $n$ 的增长趋势。

## 三、线性表

### 3.1 顺序表(数组)

**特点**:
- 逻辑相邻的元素物理上也相邻。
- 支持随机访问,$O(1)$ 时间。
- 插入/删除需要移动元素,$O(n)$ 时间。
- 存储空间连续,可能浪费。

### 3.2 链表

**单链表**:每个节点包含数据与指向下一个节点的指针。
- 插入/删除:$O(1)$ (已知前驱节点)
- 按下标访问:$O(n)$
- 不需要连续存储

**双向链表**:每个节点包含前驱与后继指针,支持 $O(1)$ 的反向遍历。

**循环链表**:尾节点的 next 指向头节点,适合环形结构。

### 3.3 顺序表 vs 链表

| 操作 | 顺序表 | 链表 |
|------|--------|------|
| 随机访问 | $O(1)$ | $O(n)$ |
| 头部插入/删除 | $O(n)$ | $O(1)$ |
| 尾部插入/删除 | $O(1)$ (均摊) | $O(n)$ (需遍历) |
| 空间利用率 | 可能有浪费 | 指针有额外开销 |

## 四、栈

### 4.1 定义

栈是**后进先出**(LIFO)的线性表,只允许在表的一端(栈顶)进行插入(push)与删除(pop)。

### 4.2 应用

- **函数调用栈**:保存函数局部变量与返回地址
- **表达式求值**:中缀转后缀,后缀表达式求值
- **括号匹配**:扫描字符串,左括号入栈,右括号出栈
- **深度优先搜索(DFS)**:保存待访问节点
- **浏览器后退**:记录历史页面

### 4.3 实现

```python
class Stack:
    def __init__(self):
        self.items = []
    def push(self, x):
        self.items.append(x)
    def pop(self):
        return self.items.pop()
    def is_empty(self):
        return len(self.items) == 0
```

## 五、队列

### 5.1 定义

队列是**先进先出**(FIFO)的线性表,在一端(队尾)插入,另一端(队头)删除。

### 5.2 应用

- **广度优先搜索(BFS)**:保存待访问节点
- **任务调度**:CPU 进程调度、打印任务队列
- **消息队列**:生产者-消费者模型
- **缓存淘汰**:FIFO 策略

### 5.3 循环队列

为解决普通队列"假溢出"问题,采用循环数组实现。队空条件:`front == rear`,队满条件:`(rear + 1) % size == front`。

## 六、串(字符串)

### 6.1 定义

由零个或多个字符组成的有限序列,记作 $S = "a_1 a_2 \cdots a_n"$。

### 6.2 模式匹配

**朴素算法**:$O(nm)$ 时间。
**KMP 算法**:利用已匹配信息,避免回溯,$O(n + m)$ 时间。核心是构造**next 数组**(最长公共前后缀)。

## 七、典型例题

**例 1**:分析以下代码的时间复杂度:
```python
def foo(n):
    s = 0
    for i in range(n):
        for j in range(i, n):
            s += 1
    return s
```

解:内层循环执行 $n + (n-1) + \cdots + 1 = n(n+1)/2$ 次,故时间复杂度为 $O(n^2)$。

**例 2**:用栈判断字符串 `"({[<>]})"` 是否括号匹配。

解:依次读取字符,左括号入栈,右括号出栈比较。
- `(` 入栈 → 栈: `[(]`
- `{` 入栈 → 栈: `[(, {]`
- `[` 入栈 → 栈: `[(, {, []`
- `<` 入栈 → 栈: `[(, {, [, <]`
- `>` 匹配 `<` → 出栈 → 栈: `[(, {, []`
- `]` 匹配 `[` → 出栈 → 栈: `[(, {]`
- `}` 匹配 `{` → 出栈 → 栈: `[(]`
- `)` 匹配 `(` → 出栈 → 栈: `[]`

最终栈空,匹配成功。

**例 3**:数组 `[5, 2, 8, 4, 9, 1]` 用快速排序的第一趟划分(以 5 为基准)。

解:从右向左找小于 5 的:1,交换到左端;从左向右找大于 5 的:8,交换到右端。重复直到相遇。
- 初始: `[5, 2, 8, 4, 9, 1]`
- low=0, high=5,基准=5
- high=5 找到 1 < 5,交换到 low: `[1, 2, 8, 4, 9, 5]`
- low=1 找到 8 > 5,交换到 high: `[1, 2, 5, 4, 9, 8]`
- low=2 找到 4 < 5(low=high=2),交换: `[1, 2, 4, 5, 9, 8]`
- 基准 5 归位:low=high=2 位置

一趟划分结果:基准 5 左侧 `[1, 2, 4]` 均小于 5,右侧 `[9, 8]` 均大于 5。
