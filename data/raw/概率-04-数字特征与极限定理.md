# 数字特征与极限定理

> 合成讲义 · 仅供 RAG 系统测试使用 · 学科:概率论与数理统计

## 一、数学期望

### 1.1 离散型随机变量的期望

设 $X$ 取值 $x_k$ 概率为 $p_k$ ($k = 1, 2, \ldots$),若 $\sum_{k} |x_k| p_k < \infty$,则:
$$E(X) = \sum_{k} x_k p_k$$
称为 $X$ 的**数学期望**(均值)。

### 1.2 连续型随机变量的期望

设 $X$ 的密度为 $f(x)$,若 $\int_{-\infty}^{+\infty} |x| f(x) dx < \infty$,则:
$$E(X) = \int_{-\infty}^{+\infty} x f(x) dx$$

### 1.3 期望的性质

- **常数**:$E(C) = C$
- **线性**:$E(aX + bY + c) = aE(X) + bE(Y) + c$
- **独立**:若 $X, Y$ 独立,则 $E(XY) = E(X) E(Y)$
- **推广**:$E[g(X)] = \sum_k g(x_k) p_k$(离散)或 $\int g(x) f(x) dx$(连续)

## 二、方差

### 2.1 定义

设 $E(X) = \mu$ 存在,若 $E[(X - \mu)^2] < \infty$,则:
$$D(X) = E[(X - \mu)^2] = E(X^2) - [E(X)]^2$$
称为 $X$ 的**方差**。$\sigma(X) = \sqrt{D(X)}$ 称为**标准差**。

### 2.2 常用分布的期望与方差

| 分布 | 期望 | 方差 |
|------|------|------|
| 0-1 分布 $B(1, p)$ | $p$ | $p(1-p)$ |
| 二项分布 $B(n, p)$ | $np$ | $np(1-p)$ |
| 泊松分布 $P(\lambda)$ | $\lambda$ | $\lambda$ |
| 均匀分布 $U(a, b)$ | $(a+b)/2$ | $(b-a)^2/12$ |
| 指数分布 $\text{Exp}(\lambda)$ | $1/\lambda$ | $1/\lambda^2$ |
| 正态分布 $N(\mu, \sigma^2)$ | $\mu$ | $\sigma^2$ |

### 2.3 方差的性质

- $D(C) = 0$
- $D(aX + b) = a^2 D(X)$
- 若 $X, Y$ 独立,则 $D(X \pm Y) = D(X) + D(Y)$

## 三、协方差与相关系数

### 3.1 协方差

$$\text{Cov}(X, Y) = E[(X - E(X))(Y - E(Y))] = E(XY) - E(X) E(Y)$$

**性质**:
- $\text{Cov}(X, X) = D(X)$
- $\text{Cov}(X, Y) = \text{Cov}(Y, X)$
- $\text{Cov}(aX + b, cY + d) = ac \cdot \text{Cov}(X, Y)$
- $D(X \pm Y) = D(X) + D(Y) \pm 2\text{Cov}(X, Y)$

### 3.2 相关系数

$$\rho_{XY} = \frac{\text{Cov}(X, Y)}{\sqrt{D(X) D(Y)}}$$

**性质**:
- $|\rho_{XY}| \leq 1$
- $|\rho_{XY}| = 1$ 当且仅当 $X$ 与 $Y$ 几乎处处线性相关
- 若 $X$ 与 $Y$ 独立,则 $\rho_{XY} = 0$ (反之不成立)
- $\rho_{XY} = 0$ 称 $X$ 与 $Y$ **不相关**

**注意**:独立 $\Rightarrow$ 不相关,但不相关 $\not\Rightarrow$ 独立(对正态分布除外)。

## 四、矩与矩母函数

### 4.1 矩

- **$k$ 阶原点矩**:$E(X^k)$
- **$k$ 阶中心矩**:$E[(X - E(X))^k]$
- 期望是一阶原点矩,方差是二阶中心矩。

### 4.2 矩母函数(MGF)

$$M_X(t) = E(e^{tX})$$
若 $M_X(t)$ 在 0 的某邻域内有限,则 $X$ 的分布由 $M_X(t)$ 唯一确定。

**性质**:
- $E(X) = M_X'(0)$,$D(X) = M_X''(0) - [M_X'(0)]^2$
- 若 $X, Y$ 独立,则 $M_{X+Y}(t) = M_X(t) M_Y(t)$

## 五、大数定律

### 5.1 切比雪夫不等式

设 $E(X) = \mu$,$D(X) = \sigma^2$,则对任意 $\varepsilon > 0$:
$$P(|X - \mu| \geq \varepsilon) \leq \frac{\sigma^2}{\varepsilon^2}$$
这是大数定律证明的核心工具。

### 5.2 切比雪夫大数定律

设 $X_1, X_2, \ldots$ 相互独立,期望 $\mu_i$、方差 $\sigma_i^2$ 存在且 $\sigma_i^2 \leq C$。则对任意 $\varepsilon > 0$:
$$\lim_{n \to \infty} P\left( \left| \frac{1}{n} \sum_{i=1}^{n} X_i - \frac{1}{n} \sum_{i=1}^{n} \mu_i \right| < \varepsilon \right) = 1$$

### 5.3 伯努利大数定律

设 $n_A$ 是 $n$ 次独立重复试验中事件 $A$ 发生的次数,$p$ 是每次试验中 $A$ 发生的概率,则:
$$\lim_{n \to \infty} P\left( \left| \frac{n_A}{n} - p \right| < \varepsilon \right) = 1$$
频率依概率收敛到概率。

### 5.4 辛钦大数定律

设 $X_1, X_2, \ldots$ 独立同分布,期望 $E(X_i) = \mu$ 存在,则:
$$\frac{1}{n} \sum_{i=1}^{n} X_i \xrightarrow{P} \mu$$

## 六、中心极限定理

### 6.1 独立同分布情形(列维-林德伯格)

设 $X_1, X_2, \ldots$ 独立同分布,$E(X_i) = \mu$,$D(X_i) = \sigma^2 > 0$,则:
$$\frac{\sum_{i=1}^{n} X_i - n\mu}{\sigma \sqrt{n}} \xrightarrow{d} N(0, 1)$$
即当 $n$ 充分大时,$\sum_{i=1}^{n} X_i$ 近似服从 $N(n\mu, n\sigma^2)$。

### 6.2 棣莫弗-拉普拉斯

设 $Y_n \sim B(n, p)$,则:
$$\frac{Y_n - np}{\sqrt{np(1-p)}} \xrightarrow{d} N(0, 1)$$
即二项分布在 $n$ 大时近似正态。这是中心极限定理的特例。

### 6.3 中心极限定理的应用

1. **二项分布的正态近似**:$B(n, p) \approx N(np, np(1-p))$,$n$ 大、$p$ 不太接近 0 或 1 时精度好。
2. **独立随机变量和的近似**:任何独立随机变量之和,$n$ 充分大时都接近正态。

## 七、典型例题

**例 1**:设 $X$ 的密度为 $f(x) = \begin{cases} 2x, & 0 \leq x \leq 1 \\ 0, & \text{其他} \end{cases}$,求 $E(X)$ 与 $D(X)$。

解:
$$E(X) = \int_0^1 x \cdot 2x \, dx = \int_0^1 2x^2 dx = \frac{2}{3}$$
$$E(X^2) = \int_0^1 x^2 \cdot 2x \, dx = \int_0^1 2x^3 dx = \frac{1}{2}$$
$$D(X) = E(X^2) - [E(X)]^2 = \frac{1}{2} - \frac{4}{9} = \frac{1}{18}$$

**例 2**:设 $X_1, X_2, \ldots, X_{100}$ 独立同分布,$E(X_i) = 2$,$D(X_i) = 0.04$。用中心极限定理求 $P(\sum X_i > 210)$ 的近似值。

解:$E(\sum X_i) = 200$,$D(\sum X_i) = 4$,$\sigma = 2$。

由中心极限定理:
$$P\left( \frac{\sum X_i - 200}{2} > \frac{210 - 200}{2} \right) = P(Z > 5) \approx 0$$
(标准正态分布 $P(Z > 5)$ 几乎为 0,实际为 $2.87 \times 10^{-7}$)。

**例 3**:设 $X_1, X_2, \ldots, X_n$ 独立同服从 $P(\lambda)$,用大数定律证明 $\frac{1}{n} \sum X_i$ 依概率收敛到 $\lambda$。

证明:由辛钦大数定律,$\{X_i\}$ 独立同分布,期望 $E(X_i) = \lambda$ 存在,故:
$$\frac{1}{n} \sum_{i=1}^{n} X_i \xrightarrow{P} \lambda$$

这说明泊松分布的参数 $\lambda$ 可以用样本均值来估计。
