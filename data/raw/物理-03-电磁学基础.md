# 电磁学基础

> 合成讲义 · 仅供 RAG 系统测试使用 · 学科:大学物理

## 一、电场

### 1.1 库仑定律

真空中两个静止点电荷之间的相互作用力,大小与电量乘积成正比,与距离平方成反比,方向沿连线:
$$F = \frac{1}{4\pi\varepsilon_0} \frac{q_1 q_2}{r^2}$$
其中 $\varepsilon_0 = 8.85 \times 10^{-12}$ F/m 是真空介电常数,$\frac{1}{4\pi\varepsilon_0} = 9.0 \times 10^9$ N·m²/C²。

### 1.2 电场强度

电场中某点的电场强度定义为:
$$\vec{E} = \frac{\vec{F}}{q_0}$$
其中 $q_0$ 是试探电荷(电量足够小,不改变原电场)。

**点电荷的电场**:
$$\vec{E} = \frac{1}{4\pi\varepsilon_0} \frac{q}{r^2} \hat{r}$$

**点电荷系的电场**(叠加原理):
$$\vec{E} = \sum_{i} \vec{E}_i = \sum_{i} \frac{1}{4\pi\varepsilon_0} \frac{q_i}{r_i^2} \hat{r}_i$$

### 1.3 电场线

为形象描述电场分布引入的假想曲线,规定:
- 切线方向为该点电场方向。
- 密度表示电场强度大小。

**特点**:始于正电荷(或无穷远),止于负电荷(或无穷远);不相交、不闭合。

## 二、电势

### 2.1 电势能

电荷 $q$ 在电场中某点的电势能:
$$E_p = q \int_{P}^{P_0} \vec{E} \cdot d\vec{l}$$
其中 $P_0$ 是电势能零点(常取无穷远或大地)。

### 2.2 电势

单位正电荷在该点的电势能:
$$V_P = \frac{E_p}{q} = \int_{P}^{P_0} \vec{E} \cdot d\vec{l}$$

**点电荷的电势**(取无穷远为零点):
$$V = \frac{1}{4\pi\varepsilon_0} \frac{q}{r}$$

### 2.3 等势面

电势相等的点构成的面称为**等势面**。特点:
- 等势面与电场线处处正交。
- 沿等势面移动电荷,电场不做功。
- 等势面越密,电场越强。

## 三、电容

### 3.1 定义

电容是描述电容器储存电荷能力的物理量:
$$C = \frac{Q}{U}$$
其中 $Q$ 是任一极板电量,$U$ 是两极板电压。单位为法拉(F)。

### 3.2 平行板电容器

$$C = \frac{\varepsilon S}{4\pi k d}$$
其中 $S$ 是极板面积,$d$ 是板间距,$\varepsilon$ 是介电常数,$k$ 是静电力常量。

### 3.3 电容器的连接

**并联**:$C = C_1 + C_2 + \cdots$(总电容增大,电压相同)
**串联**:$\frac{1}{C} = \frac{1}{C_1} + \frac{1}{C_2} + \cdots$(总电容减小,电量相同)

### 3.4 电场能量

电容器储存的能量:
$$W = \frac{1}{2} C U^2 = \frac{Q^2}{2C} = \frac{1}{2} Q U$$

电场能量密度:
$$w = \frac{1}{2} \varepsilon E^2$$

## 四、稳恒电流

### 4.1 电流

$$I = \frac{q}{t}$$
方向规定为正电荷定向移动的方向。

### 4.2 电阻与欧姆定律

**电阻**:$R = \rho \frac{L}{S}$,$\rho$ 是电阻率。

**欧姆定律**:$I = \frac{U}{R}$ 或 $U = IR$。

### 4.3 电阻的串并联

- **串联**:$R = R_1 + R_2 + \cdots$(各处电流相同,电压分担)
- **并联**:$\frac{1}{R} = \frac{1}{R_1} + \frac{1}{R_2} + \cdots$(两端电压相同,电流分担)

### 4.4 电功率

$$P = UI = I^2 R = \frac{U^2}{R}$$

## 五、磁场

### 5.1 磁感应强度

磁场中某点的磁感应强度 $\vec{B}$ 是矢量,大小定义为:
$$B = \frac{F_{max}}{qv}$$
方向为该点小磁针 N 极的指向。单位:特斯拉(T)。

### 5.2 洛伦兹力

运动电荷在磁场中受的力:
$$\vec{F} = q \vec{v} \times \vec{B}$$
大小:$F = q v B \sin\theta$ ($\theta$ 是 $\vec{v}$ 与 $\vec{B}$ 的夹角)。

**特点**:
- 始终垂直于 $\vec{v}$,故不做功。
- 当 $\vec{v} \parallel \vec{B}$ 时,$F = 0$,电荷做匀速直线运动。
- 当 $\vec{v} \perp \vec{B}$ 时,电荷做匀速圆周运动,半径 $r = \frac{mv}{qB}$,周期 $T = \frac{2\pi m}{qB}$。

### 5.3 安培力

电流元在磁场中受的力:
$$d\vec{F} = I d\vec{l} \times \vec{B}$$
整段直导线:$F = BIL \sin\theta$。

### 5.4 毕奥-萨伐尔定律

电流元产生的磁感应强度:
$$d\vec{B} = \frac{\mu_0}{4\pi} \frac{I d\vec{l} \times \hat{r}}{r^2}$$
其中 $\mu_0 = 4\pi \times 10^{-7}$ T·m/A 是真空磁导率。

**应用**:
- 无限长直导线:$B = \frac{\mu_0 I}{2\pi r}$
- 圆电流圆心:$B = \frac{\mu_0 I}{2R}$
- 螺线管内部:$B = \mu_0 n I$ ($n$ 是单位长度匝数)

## 六、电磁感应

### 6.1 法拉第电磁感应定律

感应电动势的大小等于磁通量的变化率:
$$\varepsilon = -\frac{d\Phi}{dt}$$
负号表示感应电动势的方向(楞次定律)。

磁通量:$\Phi = \vec{B} \cdot \vec{S} = B S \cos\theta$。

### 6.2 楞次定律

感应电流的方向总是使它所产生的磁场**阻碍**引起感应电流的磁通量的变化。

### 6.3 自感与互感

**自感电动势**:$\varepsilon_L = -L \frac{dI}{dt}$,$L$ 是自感系数。
**互感电动势**:$\varepsilon_M = -M \frac{dI}{dt}$,$M$ 是互感系数。

### 6.4 磁场能量

电感储存的能量:
$$W = \frac{1}{2} L I^2$$

磁场能量密度:
$$w = \frac{B^2}{2\mu_0}$$

## 七、典型例题

**例 1**:两个点电荷 $q_1 = 2 \times 10^{-6}$ C 和 $q_2 = -4 \times 10^{-6}$ C,相距 0.3 m。求中点处的电场强度。

解:中点距每个电荷 $r = 0.15$ m。
$E_1 = \frac{1}{4\pi\varepsilon_0} \frac{q_1}{r^2} = 9 \times 10^9 \times \frac{2 \times 10^{-6}}{0.0225} = 8 \times 10^5$ N/C(指向 $q_2$)
$E_2 = \frac{1}{4\pi\varepsilon_0} \frac{|q_2|}{r^2} = 9 \times 10^9 \times \frac{4 \times 10^{-6}}{0.0225} = 1.6 \times 10^6$ N/C(也指向 $q_2$)
$E = E_1 + E_2 = 2.4 \times 10^6$ N/C,方向由 $q_1$ 指向 $q_2$。

**例 2**:一段长 0.5 m 的直导线,通有 2 A 电流,与磁场方向成 30° 夹角,磁感应强度 $B = 0.4$ T。求安培力。

解:$F = B I L \sin\theta = 0.4 \times 2 \times 0.5 \times \sin 30° = 0.4 \times 2 \times 0.5 \times 0.5 = 0.2$ N。

**例 3**:在 $B = 0.5$ T 的匀强磁场中,长 0.2 m 的导线以 4 m/s 垂直于磁场方向运动,求感应电动势。

解:$\varepsilon = BLv = 0.5 \times 0.2 \times 4 = 0.4$ V。
