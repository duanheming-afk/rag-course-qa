# 机械振动与机械波

> 合成讲义 · 仅供 RAG 系统测试使用 · 学科:大学物理

## 一、机械振动

### 1.1 简谐振动

**定义**:物体在平衡位置附近作周期性往复运动,位移随时间按正弦或余弦规律变化。

$$x(t) = A \cos(\omega t + \varphi)$$

其中:
- $A$:振幅(最大位移绝对值)
- $\omega$:角频率(rad/s)
- $\varphi$:初相位
- $T = 2\pi/\omega$:周期
- $f = 1/T$:频率
- $\omega t + \varphi$:相位

### 1.2 简谐振动的特征量

- **速度**:$v = \frac{dx}{dt} = -A\omega \sin(\omega t + \varphi)$,最大速度 $v_{max} = A\omega$
- **加速度**:$a = \frac{d^2 x}{dt^2} = -A\omega^2 \cos(\omega t + \varphi) = -\omega^2 x$,最大加速度 $a_{max} = A\omega^2$

### 1.3 振动的能量

**动能**:$E_k = \frac{1}{2} m v^2 = \frac{1}{2} m A^2 \omega^2 \sin^2(\omega t + \varphi)$

**势能**:$E_p = \frac{1}{2} k x^2 = \frac{1}{2} k A^2 \cos^2(\omega t + \varphi)$

**总机械能**:$E = E_k + E_p = \frac{1}{2} k A^2 = \frac{1}{2} m A^2 \omega^2$ (守恒)

### 1.4 单摆与弹簧振子

**弹簧振子**:$\omega = \sqrt{k/m}$,$T = 2\pi \sqrt{m/k}$

**单摆**(小角度):$\omega = \sqrt{g/l}$,$T = 2\pi \sqrt{l/g}$

## 二、阻尼振动与受迫振动

### 2.1 阻尼振动

受摩擦或其他阻力作用,振幅随时间衰减的振动。
- **欠阻尼**:振幅指数衰减,仍能振动
- **临界阻尼**:最快回到平衡位置
- **过阻尼**:缓慢回到平衡位置

### 2.2 受迫振动

系统在周期性外力(驱动力)作用下的振动。稳定后,系统振动频率等于驱动力频率。

**共振**:当驱动力频率接近系统固有频率时,振幅达到最大值。

## 三、机械波

### 3.1 波的概念

**波**:振动在介质中的传播。
**横波**:质点振动方向与波传播方向**垂直**(如绳波)。
**纵波**:质点振动方向与波传播方向**平行**(如声波)。

### 3.2 波动的描述

**波长** $\lambda$:一个完整波的长度。
**周期** $T$ / **频率** $f$:波的周期/频率。
**波速** $v$:波传播的速度,$v = \lambda f = \lambda / T$。

### 3.3 平面简谐波的波函数

设波沿 $x$ 正方向传播:
$$y(x, t) = A \cos\left[ \omega \left(t - \frac{x}{v}\right) + \varphi \right] = A \cos\left[ \omega t - \frac{2\pi}{\lambda} x + \varphi \right]$$

若沿 $x$ 负方向传播:
$$y(x, t) = A \cos\left[ \omega \left(t + \frac{x}{v}\right) + \varphi \right]$$

### 3.4 波的能量

介质中某体元的能量密度:
$$w = \rho \omega^2 A^2 \sin^2\left[\omega \left(t - \frac{x}{v}\right) + \varphi\right]$$
平均能量密度:$\bar{w} = \frac{1}{2} \rho \omega^2 A^2$。

**平均能流密度**(波的强度):
$$I = \frac{1}{2} \rho v \omega^2 A^2$$

## 四、波的叠加与干涉

### 4.1 叠加原理

两列波在空间相遇时,介质中质点的位移等于各列波单独存在时位移的矢量和。

### 4.2 相干波

频率相同、振动方向相同、相位差恒定的两列波叠加,会产生稳定的强弱分布——**干涉**。

### 4.3 干涉条件

设两列相干波在某点 $P$ 的相位差为 $\Delta\varphi$:
- $\Delta\varphi = 2k\pi$ ($k$ 为整数)→ 干涉**加强**,振幅 $A = A_1 + A_2$
- $\Delta\varphi = (2k+1)\pi$ → 干涉**相消**,振幅 $A = |A_1 - A_2|$

相位差由波程差 $\delta$ 决定:$\Delta\varphi = 2\pi \delta / \lambda$。

### 4.4 驻波

两列振幅相同、传播方向相反的相干波叠加形成**驻波**。
$$y = 2A \cos(2\pi x / \lambda) \cos(\omega t)$$

- **波腹**($|2A \cos(2\pi x/\lambda)|$ 最大,即 $x = k\lambda/2$):振幅最大
- **波节**($2A \cos(2\pi x/\lambda) = 0$,即 $x = (2k+1)\lambda/4$):振幅为 0
- 相邻波节/波腹间距为 $\lambda/2$

## 五、声波

### 5.1 声速

在空气中:$v = \sqrt{\gamma R T / M}$,$\gamma$ 是比热容比,$T$ 是温度,$M$ 是摩尔质量。
20°C 时声速约 343 m/s。

### 5.2 声强与声强级

**声强**:$I = \frac{1}{2} \rho v \omega^2 A^2$

**声强级**:$L = 10 \log_{10}(I / I_0)$ dB,其中 $I_0 = 10^{-12}$ W/m² 是基准声强。

**例**:轻声说话约 40 dB,正常对话 60 dB,马路交通 80 dB,飞机起飞 120 dB。

### 5.3 多普勒效应

波源或观察者相对介质运动时,观察者接收到的频率与波源频率不同:
$$f' = \frac{v \pm v_o}{v \mp v_s} f$$

其中 $v$ 是波速,$v_o$ 是观察者速度(趋近为正),$v_s$ 是波源速度(趋近为负)。

## 六、典型例题

**例 1**:一质点作简谐振动,$x = 0.05 \cos(4\pi t + \pi/3)$ (m, s)。求振幅、周期、最大速度和最大加速度。

解:$A = 0.05$ m,$\omega = 4\pi$ rad/s。
$T = 2\pi / \omega = 0.5$ s。
$v_{max} = A\omega = 0.05 \times 4\pi = 0.2\pi \approx 0.628$ m/s。
$a_{max} = A\omega^2 = 0.05 \times 16\pi^2 = 0.8\pi^2 \approx 7.9$ m/s²。

**例 2**:两列相干波在某点 $P$ 的波程差为 $\lambda/3$。问该点是加强还是减弱?

解:相位差 $\Delta\varphi = 2\pi \cdot (\lambda/3) / \lambda = 2\pi/3$,既非 $2k\pi$ 也非 $(2k+1)\pi$,故既不加强也不减弱,只是中间状态。

**例 3**:一列波在介质中传播,波速 $v = 300$ m/s,频率 $f = 500$ Hz,振幅 $A = 0.02$ m。求波长、周期和强度(设介质密度 $\rho = 1.3$ kg/m³)。

解:$\lambda = v/f = 300/500 = 0.6$ m。
$T = 1/f = 0.002$ s,$\omega = 2\pi f = 1000\pi$ rad/s。
$I = \frac{1}{2} \rho v \omega^2 A^2 = 0.5 \times 1.3 \times 300 \times (1000\pi)^2 \times (0.02)^2$
$= 0.5 \times 1.3 \times 300 \times 10^6 \pi^2 \times 4 \times 10^{-4}$
$\approx 7.7 \times 10^5 \times \pi^2 \approx 7.6 \times 10^6$ W/m²。
