## 一、宏观经济指标

### 1.1 国内生产总值(GDP)

**GDP**:一国(或地区)在一定时期内所有常住单位生产的最终产品和服务的市场价值总和。

**计算方法**:
- **生产法**:增加值总和
- **收入法**:工资 + 利润 + 利息 + 租金 + 间接税
- **支出法**:$\text{GDP} = C + I + G + (X - M)$

其中:
- $C$:居民消费
- $I$:投资(固定资本形成 + 存货增加)
- $G$:政府购买
- $X - M$:净出口

**GDP 与 GNP 区别**:
- GDP 强调"地域"(在国内生产)
- GNP 强调"国民"(本国居民生产)
- $\text{GNP} = \text{GDP} + \text{来自国外的净要素收入}$

### 1.2 国民收入(NI)

$$\text{NI} = \text{GDP} - \text{折旧} - \text{间接税} - \text{企业转移支付} + \text{政府补贴}$$

### 1.3 物价水平

**CPI**(消费者价格指数):反映居民日常消费商品价格变动的指数。
$$\text{CPI} = \frac{\text{报告期价格}}{\text{基期价格}} \times 100$$

**PPI**(生产者价格指数):反映生产者出厂价格变动。
**GDP 平减指数**:$\text{GDP 平减指数} = \frac{\text{名义 GDP}}{\text{实际 GDP}} \times 100$

**通货膨胀**:
- 爬行通胀:CPI 涨幅 < 3%
- 温和通胀:3-10%
- 严重通胀:> 10%
- 恶性通胀:三位数以上

### 1.4 失业率

$$\text{失业率} = \frac{\text{失业人数}}{\text{劳动力人数}} \times 100\%$$

**奥肯定律**:失业率每上升 1%,GDP 增长率下降约 2%。

## 二、收入-支出模型(凯恩斯模型)

### 2.1 消费函数

$$C = a + bY_d$$
其中 $Y_d$ 是可支配收入,$b = MPC$ 是边际消费倾向,$0 < b < 1$。

**平均消费倾向**:$\text{APC} = C / Y_d > b$(因 $a > 0$)

### 2.2 储蓄函数

$$S = -a + (1-b)Y_d$$
$1 - b = MPS$ 是边际储蓄倾向。

### 2.3 均衡产出

二部门经济均衡条件:总产出 = 总支出
$$Y = C + I = a + bY + I$$
$$Y^* = \frac{a + I}{1 - b}$$

**投资乘数**:
$$k = \frac{1}{1 - b} = \frac{1}{1 - \text{MPC}} = \frac{1}{\text{MPS}}$$

投资增加 $\Delta I$,产出增加 $\Delta Y = k \cdot \Delta I$。

### 2.4 三部门与四部门

**三部门(加入政府)**:
$$Y = C + I + G$$
$$T = tY$$
$$Y_d = Y - T = (1-t)Y$$
$$Y = \frac{a + I + G}{1 - b(1-t)}$$

**四部门(加入外贸)**:
$$Y = \frac{a + I + G + NX}{1 - b(1-t)}$$

## 三、IS-LM 模型

### 3.1 IS 曲线

**IS**(Investment-Saving):产品市场均衡时,利率 $r$ 与产出 $Y$ 的关系。

$$\text{IS:} \; Y = \frac{a + I_0 - dr}{1 - b(1-t)}$$

其中 $I = I_0 - dr$(投资与利率反向)。

- IS 曲线向右下方倾斜
- 财政扩张($\uparrow G$)使 IS 右移
- 投资意愿提高($\uparrow I_0$)使 IS 右移

### 3.2 LM 曲线

**LM**(Liquidity Preference-Money Supply):货币市场均衡时,$r$ 与 $Y$ 的关系。

$$\text{LM:} \; r = \frac{kY}{h} - \frac{M_0}{h}$$

其中 $L = kY - hr$(货币需求),$M = M_0$(货币供给)。

- LM 曲线向右上方倾斜
- 货币扩张($\uparrow M_0$)使 LM 右移

### 3.3 IS-LM 均衡

联立 IS 与 LM 方程,求出均衡产出 $Y^*$ 和均衡利率 $r^*$。

**政策效果**:
- **财政政策**($\uparrow G$ 或 $\downarrow T$):IS 右移,$Y \uparrow$,$r \uparrow$。挤出效应存在。
- **货币政策**($\uparrow M$):LM 右移,$Y \uparrow$,$r \downarrow$。

## 四、AD-AS 模型

### 4.1 总需求(AD)

在每一价格水平下,经济中所有部门愿意购买的产出总量。
$$AD = C + I + G + NX$$
通常价格水平与需求量反向关系,AD 曲线向右下方倾斜。

### 4.2 总供给(AS)

**短期总供给(SRAS)**:向右上方倾斜(价格上升,企业扩大生产)。
**长期总供给(LRAS)**:垂直线(取决于技术、资源,与价格无关)。

### 4.3 均衡

- AD 与 AS 交点决定短期均衡产出与价格
- 长期均衡时,产出在潜在产出水平上

### 4.4 政策效果

- **扩张性财政政策**:AD 右移,$Y \uparrow$,$P \uparrow$
- **扩张性货币政策**:AD 右移(利率下降刺激投资),$Y \uparrow$,$P \uparrow$
- **供给冲击**(如石油危机):AS 左移,$Y \downarrow$,$P \uparrow$(滞胀)

## 五、失业与通货膨胀

### 5.1 失业类型

- **摩擦性失业**:求职中的短期失业
- **结构性失业**:技能不匹配、地区不匹配
- **周期性失业**:经济周期下行导致
- **季节性失业**:季节性行业

**自然失业率**:摩擦性 + 结构性失业。低于自然失业率意味着经济过热。

### 5.2 菲利普斯曲线

**短期菲利普斯曲线**:失业率与通胀率反向关系。
$$\pi_t = \pi_{t-1} - \beta (u_t - u^*) + v_t$$

**长期菲利普斯曲线**:垂直,长期失业率不影响通胀(自然率假说)。

### 5.3 滞胀

高失业与高通胀并存(20 世纪 70 年代石油危机),菲利普斯曲线失效。

## 六、经济增长理论

### 6.1 增长指标

- **GDP 增长率**:实际 GDP 的同比增长率
- **人均 GDP**:GDP / 人口数
- **全要素生产率(TFP)**:技术进步的衡量

### 6.2 索洛增长模型

**生产函数**:$Y = F(K, L) = K^\alpha L^{1-\alpha}$ (Cobb-Douglas)

**稳态条件**:投资 = 折旧,$sY = \delta K$。

稳态人均资本:$k^* = \left(\frac{s}{\delta}\right)^{1/(1-\alpha)}$

**结论**:
- 储蓄率提高 → 稳态产出提高(但增长率最终回到原水平)
- 人口增长率降低 → 稳态产出提高
- 技术进步 → 持续增长

### 6.3 内生增长理论

通过研发、人力资本积累等机制,内生化技术进步,实现长期增长。

## 七、宏观经济政策

### 7.1 财政政策

政府通过**税收**和**支出**调节经济。
- 扩张性:减税、增加支出(应对衰退)
- 紧缩性:增税、减少支出(应对过热)

### 7.2 货币政策

中央银行通过控制**货币供给**与**利率**调节经济。
- 工具:公开市场操作、贴现率、准备金率
- 扩张性:降息、降准、买入国债
- 紧缩性:加息、升准、卖出国债

### 7.3 政策时滞

- **认识时滞**:识别经济问题需要时间
- **决策时滞**:制定与通过政策需要时间
- **执行时滞**:政策实施到生效需要时间

## 八、典型例题

**例 1**:某国名义 GDP 1000 亿,实际 GDP 800 亿,GNP 1050 亿。求 GDP 平减指数与来自国外的净要素收入。

解:$\text{GDP 平减指数} = \frac{1000}{800} \times 100 = 125$。
净要素收入 $= \text{GNP} - \text{GDP} = 1050 - 1000 = 50$ 亿(净流入)。

**例 2**:二部门经济,$C = 100 + 0.8Y$,$I = 200$。求均衡产出与投资乘数。

解:均衡: $Y = C + I = 100 + 0.8Y + 200$
$0.2Y = 300$
$Y^* = 1500$
投资乘数 $k = 1/(1-0.8) = 5$。
若投资增加到 250,$\Delta I = 50$,$\Delta Y = 5 \times 50 = 250$,$Y^* = 1750$。

**例 3**:某国 2024 年 CPI 同比上涨 3%,GDP 增长 5%,失业率 5%(自然失业率为 4%)。该国处于什么状态?

解:CPI 涨幅 3% 属于温和通胀。
GDP 增长 5% 高于趋势,经济扩张。
失业率 5% 高于自然失业率 4%。

这是一个**温和通胀 + 增长 + 略高失业**的状态。
如果自然失业率与实际失业率接近,经济接近潜在产出。
实际失业率略高,说明经济仍有扩张空间,适合采取温和的扩张性政策。
