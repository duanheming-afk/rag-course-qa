# 参数估计与假设检验

> 合成讲义 · 仅供 RAG 系统测试使用 · 学科:概率论与数理统计

## 一、数理统计基本概念

### 1.1 总体与样本

**总体**:研究对象的全体,通常对应一个随机变量 $X$,其分布称为**总体分布**。

**样本**:从总体中抽取的 $n$ 个个体 $X_1, X_2, \ldots, X_n$,要求:
1. 独立性:各 $X_i$ 相互独立。
2. 同分布性:每个 $X_i$ 与总体 $X$ 同分布。

称 $X_1, X_2, \ldots, X_n$ 为来自总体的**简单随机样本**,$n$ 为**样本容量**。

### 1.2 统计量

设 $X_1, X_2, \ldots, X_n$ 是样本,若 $g(X_1, \ldots, X_n)$ 不含任何未知参数,则称 $g$ 是一个**统计量**。

**常用统计量**:
- **样本均值**:$\bar{X} = \frac{1}{n} \sum_{i=1}^{n} X_i$
- **样本方差**:$S^2 = \frac{1}{n-1} \sum_{i=1}^{n} (X_i - \bar{X})^2$
- **样本标准差**:$S = \sqrt{S^2}$
- **样本 $k$ 阶原点矩**:$A_k = \frac{1}{n} \sum_{i=1}^{n} X_i^k$
- **样本 $k$ 阶中心矩**:$B_k = \frac{1}{n} \sum_{i=1}^{n} (X_i - \bar{X})^k$

## 二、抽样分布

### 2.1 重要定理

**定理 1**:若 $X_1, \ldots, X_n$ 来自总体 $N(\mu, \sigma^2)$,则:
- $\bar{X} \sim N(\mu, \sigma^2 / n)$
- $\frac{(n-1)S^2}{\sigma^2} \sim \chi^2(n-1)$ (卡方分布)
- $\bar{X}$ 与 $S^2$ **独立**

**定理 2**($t$ 分布):若 $X \sim N(0, 1)$,$Y \sim \chi^2(n)$,且 $X$ 与 $Y$ 独立,则:
$$T = \frac{X}{\sqrt{Y/n}} \sim t(n)$$

**定理 3**($F$ 分布):若 $U \sim \chi^2(n_1)$,$V \sim \chi^2(n_2)$,且 $U, V$ 独立,则:
$$F = \frac{U / n_1}{V / n_2} \sim F(n_1, n_2)$$

### 2.2 三大抽样分布

| 分布 | 来源 | 主要用途 |
|------|------|---------|
| $\chi^2(n)$ | $n$ 个独立 $N(0,1)$ 平方和 | 方差估计、拟合优度 |
| $t(n)$ | 标准正态 / $\sqrt{\chi^2/n}$ | 均值检验($\sigma^2$ 未知) |
| $F(n_1, n_2)$ | 两 $\chi^2$ 之比 | 方差比检验 |

## 三、点估计

### 3.1 矩估计法

用样本矩代替总体矩,解方程得到参数估计。

**步骤**:
1. 写出总体的 $k$ 阶矩(取决于参数个数)。
2. 用样本矩替换总体矩,得到方程组。
3. 求解方程组,得到参数的矩估计 $\hat{\theta}$。

### 3.2 极大似然估计(MLE)

设总体 $X$ 的密度为 $f(x; \theta)$ ($\theta$ 未知),样本 $X_1, \ldots, X_n$ 的联合密度为:
$$L(\theta) = \prod_{i=1}^{n} f(x_i; \theta)$$
称为**似然函数**。选择使 $L(\theta)$ 最大的 $\hat{\theta}$ 作为 $\theta$ 的估计,称为**极大似然估计**。

**求法**:解方程 $\frac{\partial \ln L(\theta)}{\partial \theta} = 0$。

### 3.3 估计量的评价

- **无偏性**:$E(\hat{\theta}) = \theta$
- **有效性**:在多个无偏估计中,方差最小者更有效
- **一致性**:$\hat{\theta}_n \xrightarrow{P} \theta$ ($n \to \infty$)

## 四、区间估计

### 4.1 置信区间的概念

设总体参数 $\theta$ 的估计为 $\hat{\theta}$,若由样本确定的两个统计量 $\hat{\theta}_L, \hat{\theta}_U$ 满足:
$$P(\hat{\theta}_L < \theta < \hat{\theta}_U) = 1 - \alpha$$
则称 $(\hat{\theta}_L, \hat{\theta}_U)$ 是 $\theta$ 的**置信水平**为 $1 - \alpha$ 的**置信区间**。

### 4.2 单正态总体的区间估计

设 $X \sim N(\mu, \sigma^2)$,$X_1, \ldots, X_n$ 是样本。

**(1) $\sigma^2$ 已知时 $\mu$ 的置信区间**:
$$\left( \bar{X} - \frac{\sigma}{\sqrt{n}} z_{\alpha/2}, \, \bar{X} + \frac{\sigma}{\sqrt{n}} z_{\alpha/2} \right)$$

**(2) $\sigma^2$ 未知时 $\mu$ 的置信区间**:
$$\left( \bar{X} - \frac{S}{\sqrt{n}} t_{\alpha/2}(n-1), \, \bar{X} + \frac{S}{\sqrt{n}} t_{\alpha/2}(n-1) \right)$$

**(3) $\mu$ 未知时 $\sigma^2$ 的置信区间**:
$$\left( \frac{(n-1)S^2}{\chi^2_{\alpha/2}(n-1)}, \, \frac{(n-1)S^2}{\chi^2_{1-\alpha/2}(n-1)} \right)$$

## 五、假设检验

### 5.1 基本思想

**小概率原理**:小概率事件在一次试验中几乎不发生。若小概率事件发生了,则有理由怀疑原假设。

### 5.2 检验步骤

1. 提出原假设 $H_0$ 与备择假设 $H_1$。
2. 选取检验统计量(在 $H_0$ 成立时分布已知)。
3. 给定显著性水平 $\alpha$(通常 0.05 或 0.01)。
4. 确定拒绝域。
5. 由样本计算统计量值,判断是否落入拒绝域。

### 5.3 两类错误

- **第一类错误**(弃真):$H_0$ 真但拒绝 $H_0$,概率为 $\alpha$。
- **第二类错误**(取伪):$H_0$ 假但接受 $H_0$,概率为 $\beta$。

### 5.4 单正态总体的均值检验

**(1) $\sigma^2$ 已知(Z 检验)**:检验 $H_0: \mu = \mu_0$
$$Z = \frac{\bar{X} - \mu_0}{\sigma / \sqrt{n}} \sim N(0, 1)$$

**(2) $\sigma^2$ 未知(t 检验)**:检验 $H_0: \mu = \mu_0$
$$T = \frac{\bar{X} - \mu_0}{S / \sqrt{n}} \sim t(n-1)$$

### 5.5 单正态总体的方差检验(卡方检验)

检验 $H_0: \sigma^2 = \sigma_0^2$
$$\chi^2 = \frac{(n-1)S^2}{\sigma_0^2} \sim \chi^2(n-1)$$

## 六、典型例题

**例 1**:设总体 $X \sim P(\lambda)$,$X_1, \ldots, X_n$ 是样本,求 $\lambda$ 的矩估计与极大似然估计。

解:**矩估计**:$E(X) = \lambda$,用 $\bar{X}$ 替换 $E(X)$,得 $\hat{\lambda} = \bar{X}$。

**MLE**:似然函数
$$L(\lambda) = \prod_{i=1}^{n} \frac{\lambda^{x_i} e^{-\lambda}}{x_i!} = \frac{\lambda^{\sum x_i} e^{-n\lambda}}{\prod x_i!}$$
对数似然:
$$\ln L = (\sum x_i) \ln \lambda - n\lambda - \sum \ln(x_i!)$$
令 $\frac{\partial \ln L}{\partial \lambda} = \frac{\sum x_i}{\lambda} - n = 0$,得 $\hat{\lambda} = \bar{X}$。

**例 2**:设 $X \sim N(\mu, \sigma^2)$,$\mu$ 未知,$\sigma^2$ 未知,$\bar{X}, S^2$ 由容量 16 的样本算得为 $\bar{X} = 5$,$S^2 = 4$。求 $\mu$ 的 95% 置信区间。

解:$\sigma^2$ 未知,使用 $t$ 分布。$n = 16$,$t_{0.025}(15) = 2.131$。
$$\bar{X} \pm t_{0.025}(15) \cdot \frac{S}{\sqrt{n}} = 5 \pm 2.131 \cdot \frac{2}{4} = 5 \pm 1.066 = (3.934, 6.066)$$

**例 3**:某厂生产元件,寿命服从正态分布,标准差 $\sigma = 100$ 小时。声称平均寿命 $\mu = 1200$ 小时。取 9 个元件测试,得 $\bar{X} = 1150$。在 $\alpha = 0.05$ 下能否接受声称?

解:检验 $H_0: \mu = 1200$ vs $H_1: \mu \neq 1200$。

$\sigma$ 已知,使用 $Z$ 检验:
$$Z = \frac{\bar{X} - \mu_0}{\sigma / \sqrt{n}} = \frac{1150 - 1200}{100 / 3} = -1.5$$

$|Z| = 1.5 < z_{0.025} = 1.96$,故不拒绝 $H_0$,可以接受声称。
