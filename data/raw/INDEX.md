## loader 兼容说明(供阶段 3 实现参考)

`docs/design.md` 中 `loader.py` 设计仅支持 PDF 解析(PyMuPDF)。本目录文件为 `.md` 格式,阶段 3 实现 loader 时需扩展:

```python
# 伪代码示例
def load_file(path: str | Path) -> list[Document]:
    suffix = Path(path).suffix.lower()
    if suffix == ".pdf":
        return load_pdf(path)
    elif suffix == ".md":
        return load_markdown(path)  # 新增:用 markdown 库解析
    else:
        raise ValueError(f"Unsupported format: {suffix}")
```

`load_markdown` 建议:
- 用 `markdown` 库将 .md 解析为 AST 或 HTML
- 按一级标题 / 二级标题切分章节(`section` 字段)
- 整个文件作为一页(简化)或按段落细分
- 保留数学公式(LaTeX)原样

`chunker.py` 与 `indexer.py` 不需修改,只需在 CLI/UI 上同时支持两种格式。
