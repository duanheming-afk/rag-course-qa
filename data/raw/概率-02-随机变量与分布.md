# 随机变量与分布

> 合成讲义 · 仅供 RAG 系统测试使用 · 学科:概率论与数理统计

## 一、随机变量的概念

### 1.1 定义

设随机试验的样本空间为 $\Omega$,若对 $\Omega$ 中的每个样本点 $\omega$,都有唯一实数 $X(\omega)$ 与之对应,则称 $X = X(\omega)$ 是定义在 $\Omega$ 上的**随机变量**。

随机变量本质上是样本空间到实数集的一个函数,用以**数量化**地表示随机现象的结果。

### 1.2 分类

- **离散型随机变量**:取值可数(或有限)。
- **连续型随机变量**:取值充满某个区间。
- **混合型**:既非纯离散也非纯连续。

## 二、离散型随机变量

### 2.1 分布律

设 $X$ 是离散型随机变量,其全部可能取值为 $x_1, x_2, \ldots$,对应概率为 $p_1, p_2, \ldots$,则称
$$P(X = x_k) = p_k, \quad k = 1, 2, \ldots$$
为 $X$ 的**分布律**(概率分布)。分布律满足:
- $p_k \geq 0$
- $\sum_{k} p_k = 1$

### 2.2 常用离散分布

**(1) 0-1 分布(伯努利分布)**

$X$ 只取 0 或 1,$P(X = 1) = p$,$P(X = 0) = 1 - p$。

**(2) 二项分布 $B(n, p)$**

$n$ 次独立伯努利试验中成功次数 $X$:
$$P(X = k) = C_n^k p^k (1-p)^{n-k}, \quad k = 0, 1, \ldots, n$$

**(3) 泊松分布 $P(\lambda)$**

$$P(X = k) = \frac{\lambda^k e^{-\lambda}}{k!}, \quad k = 0, 1, 2, \ldots$$
$\lambda > 0$ 是参数。泊松分布常用于描述单位时间内随机事件发生的次数。

## 三、随机变量的分布函数

### 3.1 定义

设 $X$ 是随机变量,$x$ 是任意实数,则函数
$$F(x) = P(X \leq x)$$
称为 $X$ 的**分布函数**(累积分布函数, CDF)。

### 3.2 性质

1. **单调非减**:$F(x)$ 关于 $x$ 单调不减。
2. **有界性**:$0 \leq F(x) \leq 1$,且 $F(-\infty) = 0$,$F(+\infty) = 1$。
3. **右连续**:$F(x^+) = F(x)$。

### 3.3 用分布函数表示概率

- $P(a < X \leq b) = F(b) - F(a)$
- $P(X = a) = F(a) - F(a^-)$

## 四、连续型随机变量

### 4.1 概率密度函数

若存在非负函数 $f(x)$,使得对任意实数 $a < b$:
$$P(a < X < b) = \int_a^b f(x) dx$$
则称 $X$ 为**连续型随机变量**,$f(x)$ 为 $X$ 的**概率密度函数**(PDF)。

**性质**:
- $f(x) \geq 0$
- $\int_{-\infty}^{+\infty} f(x) dx = 1$
- 在 $f(x)$ 连续点,$F'(x) = f(x)$
- 单点概率为 0:$P(X = a) = 0$

### 4.2 常用连续分布

**(1) 均匀分布 $U(a, b)$**

密度函数:
$$f(x) = \begin{cases} \frac{1}{b - a}, & a \leq x \leq b \\ 0, & \text{其他} \end{cases}$$

**(2) 指数分布 $\text{Exp}(\lambda)$**

密度函数:
$$f(x) = \begin{cases} \lambda e^{-\lambda x}, & x \geq 0 \\ 0, & x < 0 \end{cases}$$
$\lambda > 0$ 是参数。指数分布具有**无记忆性**:$P(X > s + t | X > s) = P(X > t)$。

**(3) 正态分布 $N(\mu, \sigma^2)$**

密度函数:
$$f(x) = \frac{1}{\sqrt{2\pi} \sigma} e^{-\frac{(x-\mu)^2}{2\sigma^2}}$$
其中 $\mu$ 是均值,$\sigma^2$ 是方差。

**标准正态分布** $N(0, 1)$:$\mu = 0$,$\sigma = 1$,密度函数:
$$\varphi(x) = \frac{1}{\sqrt{2\pi}} e^{-x^2/2}$$
分布函数记为 $\Phi(x) = \int_{-\infty}^{x} \varphi(t) dt$。$\Phi(-x) = 1 - \Phi(x)$。

**正态分布的标准化**:若 $X \sim N(\mu, \sigma^2)$,则 $Z = \frac{X - \mu}{\sigma} \sim N(0, 1)$。

## 五、随机变量函数的分布

### 5.1 离散型

若 $X$ 取值 $x_i$ 概率为 $p_i$,$Y = g(X)$ 取值 $y_j$ 概率为:
$$P(Y = y_j) = \sum_{g(x_i) = y_j} P(X = x_i)$$

### 5.2 连续型(分布函数法)

求 $Y = g(X)$ 的分布函数:
$$F_Y(y) = P(Y \leq y) = P(g(X) \leq y) = \int_{g(x) \leq y} f_X(x) dx$$

**密度函数法**(若 $g$ 严格单调且可导):
$$f_Y(y) = f_X(g^{-1}(y)) \cdot \left| \frac{d}{dy} g^{-1}(y) \right|$$

## 六、典型例题

**例 1**:设 $X$ 服从参数为 $\lambda$ 的泊松分布,求 $P(X = 2)$。

解:$P(X = 2) = \frac{\lambda^2 e^{-\lambda}}{2}$。

**例 2**:设 $X \sim N(0, 1)$,求 $P(-1 < X < 2)$。

解:$P(-1 < X < 2) = \Phi(2) - \Phi(-1) = \Phi(2) - (1 - \Phi(1)) = \Phi(2) + \Phi(1) - 1$。

查表得 $\Phi(1) \approx 0.8413$,$\Phi(2) \approx 0.9772$。
故 $P(-1 < X < 2) \approx 0.9772 + 0.8413 - 1 = 0.8185$。

**例 3**:设随机变量 $X$ 的密度函数为
$$f(x) = \begin{cases} cx^2, & 0 \leq x \leq 1 \\ 0, & \text{其他} \end{cases}$$
求:(1) 常数 $c$;(2) 分布函数 $F(x)$。

解:
(1) 由 $\int_{-\infty}^{+\infty} f(x) dx = 1$ 得:
$$\int_0^1 cx^2 dx = \frac{c}{3} = 1 \Rightarrow c = 3$$

(2) 分段求 $F(x)$:
- 当 $x < 0$:$F(x) = 0$
- 当 $0 \leq x \leq 1$:$F(x) = \int_0^x 3t^2 dt = x^3$
- 当 $x > 1$:$F(x) = 1$

$$F(x) = \begin{cases} 0, & x < 0 \\ x^3, & 0 \leq x \leq 1 \\ 1, & x > 1 \end{cases}$$
