# 树与二叉树

> 合成讲义 · 仅供 RAG 系统测试使用 · 学科:数据结构

## 一、树的基本概念

### 1.1 定义

树是 $n$ ($n \geq 0$) 个节点的有限集。当 $n = 0$ 时称为**空树**;当 $n > 0$ 时,树有且仅有一个**根节点**,其余节点可分为 $m$ ($m \geq 0$) 个互不相交的有限集 $T_1, T_2, \ldots, T_m$,每个集合本身又是一棵树,称为根节点的**子树**。

### 1.2 基本术语

- **节点的度**:节点拥有的子树数
- **树的度**:树中各节点度的最大值
- **叶子(终端)节点**:度为 0 的节点
- **分支(非终端)节点**:度不为 0 的节点
- **节点的层次**:根为第 1 层,其孩子为第 2 层,以此类推
- **树的深度(高度)**:树中节点的最大层次
- **孩子与双亲**:节点的子树根称为该节点的孩子,该节点为它们的双亲
- **兄弟**:同一双亲的孩子互为兄弟
- **祖先与子孙**:从根到某节点路径上的所有节点为该节点的祖先;某节点子树中的所有节点为该节点的子孙

## 二、二叉树

### 2.1 定义

每个节点最多有两个子树(左子树、右子树)的树。

### 2.2 特殊二叉树

- **满二叉树**:深度为 $k$ 的二叉树有 $2^k - 1$ 个节点
- **完全二叉树**:除最后一层外,每层节点数都达到最大,最后一层节点集中在左侧

### 2.3 重要性质

1. 在二叉树的第 $i$ 层上,最多有 $2^{i-1}$ 个节点。
2. 深度为 $k$ 的二叉树,最多有 $2^k - 1$ 个节点。
3. 对任何一棵二叉树 $T$,若叶子数为 $n_0$,度为 2 的节点数为 $n_2$,则 $n_0 = n_2 + 1$。
4. 具有 $n$ 个节点的完全二叉树的深度为 $\lfloor \log_2 n \rfloor + 1$。

### 2.4 存储结构

**顺序存储**:用一维数组存储,适合完全二叉树。一般二叉树会有空间浪费。

**链式存储**:每个节点含 `data`、`lchild`、`rchild` 三个域。$n$ 个节点有 $n + 1$ 个空指针域。

## 三、二叉树的遍历

### 3.1 先序遍历(根左右)

```python
def preorder(node):
    if node is None: return
    visit(node)
    preorder(node.lchild)
    preorder(node.rchild)
```

### 3.2 中序遍历(左根右)

```python
def inorder(node):
    if node is None: return
    inorder(node.lchild)
    visit(node)
    inorder(node.rchild)
```

### 3.3 后序遍历(左右根)

```python
def postorder(node):
    if node is None: return
    postorder(node.lchild)
    postorder(node.rchild)
    visit(node)
```

### 3.4 层次遍历

按树的层次,从上到下、从左到右访问节点,用队列实现。

## 四、线索二叉树

### 4.1 目的

利用二叉树中 $n+1$ 个空指针域,存放节点在某种遍历顺序下的前驱和后继信息。

### 4.2 实现

在节点中加两个标志位 `ltag` 和 `rtag`:
- `ltag = 0`:lchild 指向左孩子;`ltag = 1`:lchild 指向前驱
- `rtag = 0`:rchild 指向右孩子;`rtag = 1`:rchild 指向后继

## 五、树与森林

### 5.1 树的存储

- **双亲表示法**:每个节点存储双亲下标
- **孩子表示法**:每个节点的孩子组成链表
- **孩子兄弟表示法**:每个节点含 `firstchild` 和 `nextsibling` 指针

### 5.2 树、森林与二叉树的转换

**树 → 二叉树**:每个节点的左指针指向其第一个孩子,右指针指向其下一个兄弟。

**森林 → 二叉树**:将各树视为兄弟,合并。

**二叉树 → 树/森林**:右孩子链是原树的兄弟链。

## 六、哈夫曼树(最优二叉树)

### 6.1 概念

**路径长度**:从根到节点的路径上的边数。
**带权路径长度**:节点的权值乘以路径长度。
**树的带权路径长度(WPL)**:所有叶子节点的带权路径长度之和。

**哈夫曼树**:给定 $n$ 个权值 $\{w_1, \ldots, w_n\}$,构造的 WPL 最小的二叉树。

### 6.2 构造算法

1. 将 $n$ 个权值视为 $n$ 棵只有根节点的树,组成森林。
2. 每次选两棵权值最小的树合并,新树的根权为两子树根权之和。
3. 重复直到只剩一棵树。

### 6.3 应用:哈夫曼编码

用于数据压缩。出现频率高的字符用短编码,频率低的用长编码,总编码长度最短。

## 七、典型例题

**例 1**:一棵完全二叉树有 1000 个节点,求叶子节点数。

解:设度为 0、1、2 的节点数分别为 $n_0, n_1, n_2$。
- $n_0 + n_1 + n_2 = 1000$
- $n_0 = n_2 + 1$ (性质 3)
- 完全二叉树中 $n_1 = 0$ 或 $1$,这里 $n_1 = 1$ (因为 1000 是偶数)

故 $n_2 = 499$,$n_0 = 500$。

**例 2**:已知二叉树先序遍历为 `ABDEGCF`,中序遍历为 `DBGEACF`,画出二叉树并求后序遍历。

解:由先序第一个字符 A 为根,在中序中 A 左侧 `DBGE` 为左子树,右侧 `CF` 为右子树。
- 左子树:先序 `BDEG`,中序 `DBGE`
  - B 为根,中序中 B 左侧 `D` 为左子树,右侧 `GE` 为右子树
  - 右子树:先序 `EG`,中序 `GE`
    - E 为根,中序中 E 左侧 `G`,但 G 在先序中位于 E 之后矛盾
    - 修正:E 为根,G 在 E 的右侧(后序:GE)
- 右子树:先序 `CF`,中序 `CF`
  - C 为根,中序中 C 右侧 `F`,故 F 是 C 的右孩子

最终树结构:
```
        A
       / \
      B   C
     / \   \
    D   E   F
         \
          G
```

后序遍历:左子树后序 + 右子树后序 + 根
- 左子树后序: D, G, E, B
- 右子树后序: F, C
- 后序: D, G, E, B, F, C, A → `DGEBFCA`

**例 3**:对权值 `{5, 9, 12, 13, 16, 45}` 构造哈夫曼树,求 WPL。

解:构造过程:
- 初始: `[5, 9, 12, 13, 16, 45]`
- 选 5, 9 合并 → 14,森林: `[12, 13, 14, 16, 45]`
- 选 12, 13 合并 → 25,森林: `[14, 16, 25, 45]`
- 选 14, 16 合并 → 30,森林: `[25, 30, 45]`
- 选 25, 30 合并 → 55,森林: `[45, 55]`
- 选 45, 55 合并 → 100,根

WPL = 5×3 + 9×3 + 12×3 + 13×3 + 16×3 + 45×1 = (5+9+12+13+16)×3 + 45 = 55×3 + 45 = 165 + 45 = 210。

注意:合并顺序影响 WPL,但只要每次选最小的两个,所有正确构造的 WPL 相同。
